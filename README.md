# SampleChopper
VST3 Sampler Plugin created using C++ and JUCE.

Inspired by Tracklib's Sample Breakdown series. This plugin allows the user to highlight portions of a audio file and independently manipulate parameters including but not limited speed and pitch. Useful for searching through samples for one-shots and slicing fast samples into individual notes or hits.

In order to download the plugin, download juce and create a new project. Replace the source code with sampleChopper source code included. You may need to change parameters in your jucer file so my jucer file is also included as a guide. When in an IDE, build the plugin and it is ready to be used in a DAW.
